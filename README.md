# The New World

An AI-driven RPG prototype built with Next.js, React, TypeScript, and Tailwind CSS.

## What it does

The New World is an experimental game project focused on dynamic character creation, ancestry systems, race traits, and world-driven gameplay.

## Current Features

- Character creation system
- Race and hybrid ancestry mechanics
- Trait, strength, and weakness generation
- Faction systems
- Character appearance controls
- Character portrait generation
- Modular game logic built in TypeScript

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Git / GitHub

## Project Goal

The long-term goal is to build a dynamic RPG system where characters, races, factions, and world state can interact in ways that create more emergent gameplay.

## Status

Actively in development.
